# Smart Agriculture System - Expanded Demo

Run with Java 17+ and Maven: `mvn spring-boot:run`
Open `http://localhost:8080`

Modules: Home, Smart Analysis, Agriculture Schemes, Animal Farm, Plant & Crop Hub, Seed Centre, Farm Waste Converter, Renewable Energy, responsive demo modals, in-memory sample database, Spring Boot REST APIs.

APIs: GET /api/schemes, /api/animals, /api/plants, /api/seeds, /api/waste-solutions, /api/energy; POST /api/analysis.

The scheme catalogue is demo data, not an exhaustive/current government database. Verify live eligibility and deadlines with official authorities. Animal medicine information is educational only; diagnosis and treatment require a qualified veterinarian. Sowing/harvest months are general demo guidance and must be localized.
